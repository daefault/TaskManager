Веб-приложение для управления проектами и задачами

Запуск проекта:
1. Настроить .env файл по примеру .env.sample
2. Собрать контейнер docker-compose up -d --build

Основные возможности:
1. Управление проектами и членами проектов
2. Управление задачами внутри проекта - назначение исполнителей задач, управление статусами, дедлайнами, приоритетами задач
3. Уведомления о назначении задач 
4. Регистрация и аутентификация

Технологии:
Backend - Python 3.11 + FastAPI 
БД - PostgreSQL + SQLAlchemy + Alembic
Аутентификация - JWT токены (python-jose)
Фоновые задачи для уведомлений - Celery + Redis
Мониторинг уведомлений - flower
Тестирование - pytest + pytest-cov
Контейнеризация - Docker + Docker Compose
